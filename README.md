# На память

Прототип сайта для семейных подарочных книг ко дню рождения.

## Запуск

Из корня проекта выполните:

```sh
python3 -m http.server 8080 --directory docs
```

Откройте http://localhost:8080.

## Что работает

- Создание нескольких книг в кабинете.
- Истории и семейные рецепты от одного или нескольких авторов.
- Загрузка изображения и аудиозаписи до 10 МБ каждый.
- Редактирование и удаление материалов.
- Ручной порядок, сортировка по авторам и году события.
- Три цвета обложки и два формата предпросмотра.
- Сохранение в IndexedDB, совместимое с первым демо.

## Текущие границы

Данные остаются в конкретном браузере и на конкретном адресе сайта. Очистка данных браузера удаляет книги. Это демо без авторизации, совместного доступа с разных устройств, автоматической расшифровки, генерации иллюстраций, оплаты и заказа печати. Предпросмотр показывает структуру книги и требует отдельной подготовки перед типографией.

Личные материалы участников никогда не должны попадать в репозиторий. Вымышленный пример встроен в сайт.

## GitHub

Сайт находится в папке docs. В Settings → Pages выберите Deploy from a branch, ветку main и папку /docs, затем Save. Публикация последующих изменений в этой папке будет автоматической.

GitHub Pages допускает публичные репозитории на бесплатном тарифе. Для коммерческого сервиса с заказами потребуется подходящий хостинг согласно условиям GitHub Pages.
